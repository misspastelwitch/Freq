# Freq
Frequency visualisation project for my UXD minor.

## What's the project?
The idea of this project is to create a way to combine sound with visuals. The focus of this project is on interaction design. In this case, the focus is on using a flute or whistle to create a certain visual. It’s an interactive exhibition, where a group of 30 users are able to make sounds together and at the same time learn about how different frequencies work. 

The end result should be an experience that inspires the users to come together to create harmonies using single tone flutes and see those harmonies visualised from a frequency into a tone.
